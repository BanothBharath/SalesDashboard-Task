# 📊 Sales Dashboard – Task

## 📌 Project Overview

This project is an interactive **Sales Dashboard** created using **Microsoft Power BI** and the **Superstore Sales dataset**.

The dashboard analyzes sales performance across different time periods, regions, product categories, and profitability metrics. It provides a visual way to identify sales trends, high-performing regions, and category-level performance.

## 🎯 Objectives

- Analyze sales performance over time
- Compare sales across different regions
- Understand category-wise sales performance
- Analyze profitability and profit margins
- Identify high-performing and low-performing areas
- Present business insights through interactive Power BI visualizations

## 🛠️ Tools & Technologies

- **Microsoft Power BI**
- **CSV / Superstore Sales Dataset**
- **Data Visualization**
- **Business Intelligence**

## 📈 Key Insights

Sales Trend
Sales showed a consistent upward trend during the second half of the year, with December recording the highest sales.

Regional Performance
The West region performed the best, contributing approximately 35% of total sales.
The South region recorded the lowest sales, indicating potential opportunities for improvement.

Category Performance
Technology was the highest-performing category, contributing approximately 40% of total revenue.
Furniture contributed approximately 20% of total revenue, making it a comparatively lower-performing category.

Profitability
The East region achieved the highest profit margins despite having moderate sales, indicating relatively efficient operations.

## ▶️ How to Use

1. Download or clone this repository.
2. Open salesdashboard-task.pbix using Microsoft Power BI Desktop.
3. If required, update the dataset path to Superstore_Sales.csv.
4. Explore the interactive dashboard and visualizations.
